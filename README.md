# Image Compression using KMeans Clustering

This project demonstrates how to compress images by reducing the number of unique colors using the KMeans clustering algorithm from scikit-learn. It's implemented in a Jupyter Notebook and includes visualization of compressed images and their color palettes.

## Features

- Compress any image by reducing its color palette to a fixed number of colors.
- Visualize the original and compressed images side by side.
- Display a grid of centroid colors used in the compression.
- Save compressed images efficiently using palette-based formats like PNG.

## Concepts Used

- KMeans Clustering (unsupervised learning)
- Color quantization
- Image processing with NumPy and Pillow
- Data visualization with Matplotlib
